# BizControl

Aplicación web estática para organizar ventas, productos, inventario, gastos, clientes y reportes. Los datos se guardan localmente en el navegador mediante `localStorage`.

## Publicar en GitHub Pages
1. Descomprimí `bizcontrol-github.zip`.
2. Creá un repositorio en GitHub.
3. Subí el contenido de la carpeta `bizcontrol` al repositorio, dejando `index.html` en la raíz.
4. Entrá en **Settings → Pages**.
5. En **Build and deployment**, elegí **Deploy from a branch**.
6. Seleccioná la rama `main` y la carpeta `/(root)`, y guardá.
7. Esperá a que GitHub Pages publique el sitio y abrí el enlace que te proporcione.

## Instalar en el celular
Abrí el enlace publicado desde Safari (iPhone) o Chrome (Android). En iPhone, usá **Compartir → Agregar a pantalla de inicio**. En Android, usá el menú del navegador y elegí **Instalar aplicación** o **Agregar a pantalla de inicio**.

## Datos y copias de seguridad
La información queda guardada en el navegador y dispositivo donde se utiliza. Desde Configuración podés exportar un archivo JSON para conservar una copia. Si borrás los datos del navegador o cambiás de dispositivo, necesitás restaurar esa copia.

## Importante
BizControl es una herramienta básica de organización. Sus resultados son estimaciones basadas en los datos ingresados y no reemplazan asesoramiento contable, fiscal o financiero.
